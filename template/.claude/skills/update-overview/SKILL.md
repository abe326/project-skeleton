# update-overview

`docs/プロジェクト概要.html` は目的・思想・現在地・将来対応・構成図をまとめた**正本**。人が読む 1 枚であり、`build.py` がタスクスナップショットを書き込む場所でもある。壊さずに更新するための手順。

## 発火条件

- フェーズが移った（着手 → 開発 → 検証 → 公開 → 運用 等）
- 方針・設計原則が変わった、または ADR を追加した
- エピック（まとまった機能）が完了した
- ロードマップ（将来対応）の時期・内容・状態が動いた
- 環境構成（環境の追加・削除・構成図の変更）が変わった
- ユーザーが「概要を更新して」「現在地を直して」等と言った

## HTML の構造（触ってよい場所）

固定セクションごとにコメントマーカーが 1 対ずつある。**編集は必ずマーカーの内側だけ**。

| マーカー | 内容 | 編集 |
|:--|:--|:--|
| `updated` | 最終更新日（`YYYY-MM-DD`） | 更新のたびに今日へ |
| `purpose` | 1. 目的・背景 | 目的が変わったときだけ |
| `principles` | 2. 思想・設計原則 | 原則の追加・変更 |
| `phase` | 3. 現在地: フェーズ名と一言 | フェーズ移行時 |
| `decisions` | 直近の決定 3〜5 件（ADR / タスク ID 付き） | 決定のたびに先頭へ 1 件、5 件を超えたら末尾を落とす |
| `task-snapshot` | `build.py` が自動生成 | **手で編集しない** |
| `roadmap` | 4. 将来対応: 表（時期 / 内容 / 状態 / 関連 ID） | 行の追加・状態変更 |
| `map` | 5. 構成図と環境の入口: テキスト図 + 環境表 | 構成変更時。URL・秘密は書かず「環境情報.md 参照」 |
| `history` | 6. 更新履歴: 表（日付 / 更新箇所 / 要点、新しい順） | 更新のたびに先頭へ 1 行 |

`<style>`・`<script>`・`<nav>`・マーカーの外側・マーカーそのものは**不可侵**。

## 手順

1. **全体を Read する**（部分読みで済ませない。マーカーの位置と既存の書き方を把握する）
2. **対象マーカーの内側だけを Edit する**。`old_string` にマーカー行を含めて一意にする
3. **現在地 ⇔ 将来対応の整合を取る**。完了した項目は `roadmap` から落とし、`history` へ「完了」として記す。`phase` の一言と `roadmap` の直近行が矛盾していないか読み直す
4. **`updated` を今日の日付にし、`history` 表の先頭に 1 行足す**（日付 / 更新箇所 / 要点）
5. **タスクスナップショットを再生成する**
   ```bash
   python3 docs/案件/01_タスク管理/build.py
   ```
6. **検査する**
   ```bash
   python3 scripts/check_skeleton.py --overview
   ```
   マーカー対の欠落・重複、外部 `src` / `href` を検出する。秘密らしき文字列（`password=…` / `token: …` 等の 12 文字以上の値、`https://user:pass@…` の URL 埋め込み資格情報）は `check_skeleton.py --docs` が概要 HTML と設計書をまとめて見るので、続けて実行する。失敗したら直してから終える
7. **変更点を 3 行で報告する**（どのセクションを・何から何へ・関連 ID）

## 書き方の決めごと

- 一文は短く。「現在地」は 1〜2 文、決定は 1 行 + ID
- 時点の状態ではなく**決定した事実**を書く（「検討中」を長く残さない。検討中はタスク md へ）
- URL・ID・パスワード・鍵は書かない。環境の入口は「名前 / 用途 / 正本の所在（環境情報.md §n）」の形にとどめる
- `{{PROJECT_NAME}}` 等の生成時プレースホルダが残っていたら、そのセクションを編集するついでに実名へ置き換える

## 禁止事項

- マーカーの外側・`<style>`・`<script>`・`<nav>` を編集する
- `task-snapshot` を手で書き換える（`build.py` に上書きされる）
- 概要 HTML に秘密の実値を書く
- `history` を更新せずに本文だけ変える
- `check_skeleton.py --overview` を通さずに終える
