# ドキュメント管理ルール

## docs/ の構成

```
docs/
├── README.md                 ← 索引と推奨読書順
├── プロジェクト概要.html       ← 目的・思想・現在地・将来対応・構成図（update-overview スキルで更新）
├── 案件/                     ← 共有記録（Git 管理対象）
│   ├── README.md
│   ├── 01_タスク管理/         ← 作業の正本（タスク md ＋ new.py / close.py / screen.py / build.py）
│   │   ├── open/  closed/    ←   <ID>_タイトル.md
│   │   └── index.html / data.js / areas.json / screens/
│   ├── 02_打合せ/             ← 打合せ記録（YYYYMMDD_タイトル.md）
│   └── 確認依頼一覧.md         ← 相手に確認・判断してほしいことの一覧
└── 設計書/                   ← 設計の正本（01-overview / 02-architecture / decisions/）
```

- `docs/` は **Git 管理対象で共有する前提**。秘密（URL・ID・パスワード・鍵）は書かない（`.claude/rules/secrets.md`）。実値の正本は `環境情報.md`、関係者・日程は `案件情報.md`（どちらもルート直下・Git 管理外）
- 作業単位は **タスク**（`01_タスク管理/` の md）。起票・クローズは `task` スキル（`docs/案件/01_タスク管理/README.md`）

## 資料の配置先

| 種別 | 配置先 |
|------|--------|
| 作業の経緯・設計判断・検討記録 | 該当タスク md（`01_タスク管理/open/`・`closed/` の `<ID>_*.md`）本文へ追記 |
| タスクに付随する成果物（提出資料・サンプル・スクショ等で残す価値のあるもの） | タスク md と同じフォルダに `<ID>_内容_YYYYMMDD.拡張子` で併置（例: `UI-01_画面スクショ_20260101.png`） |
| 打合せの要約・文字起こし | `02_打合せ/YYYYMMDD_タイトル.md` |
| 相手に確認・判断してほしいこと | `確認依頼一覧.md`（片付いたら `[x]` にして履歴節へ） |
| 横断的に参照される設計判断（昇格） | `docs/設計書/decisions/ADR-NNN-<短い英語>.md`（`ADR-000-テンプレート.md` の型） |
| 恒久的な仕様・方針 | `docs/設計書/`（詳細はコードが正本。設計書は概要・方針） |
| タスク md から参照する証跡（大きい・機密・生データ） | `.work/証跡/<タスクID>_内容/`（`.claude/rules/work-area.md`） |
| 受領した一次資料そのもの | `.work/機密/<タスクID>_内容/`（同上） |
| 使い捨ての中間生成物 | `.work/一時/YYYYMMDD_用途/`（`scratch` スキル） |

どのタスクにも紐づかない大きな資料の置き場に迷う場合は、勝手に新フォルダを作らず**ユーザーに確認する**（番号付きカテゴリの新設はユーザー判断）。

## 設計書と ADR

- `docs/設計書/` は**正本**。実装と食い違ったら、まず設計書側で「どちらが正か」を確定してから下流を合わせる
- タスク md に書いた判断のうち、**複数タスク・複数領域に効くもの**は ADR へ昇格する。ADR は 1 判断 1 ファイル、節は Status / Context / Decision / 却下した案 / Consequences / 関連
- ADR を足したら `decisions/README.md` の索引と、概要 HTML の「直近の決定」（`update-overview` スキル）を同じ作業で更新する

## 命名規則

- **タスク md**: `<ID>_タイトル.md`（ID は領域プレフィックス＋連番。領域は `01_タスク管理/areas.json`）
- **タスク付随資料**: `<ID>_内容_YYYYMMDD.拡張子`
- **打合せ**: `YYYYMMDD_タイトル.md`
- **ADR**: `ADR-NNN-<短い英語>.md`
- **日本語 OK**: フォルダ名・ファイル名ともに日本語使用可

## アーカイブ

過去の記録をアーカイブ用フォルダ（`_アーカイブ/` 等）へ凍結したら、**そこへ新しいファイルを追加しない**。参照は自由。
