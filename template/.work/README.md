# `.work/` — 作業領域の索引

Git 管理外（`.gitignore` の `.work/`）の作業領域。**枠は「消してよいか」と「誰が参照するか」で決まる**。配置ルールの正本は `.claude/rules/work-area.md`。ここは**実データの索引**と**旧パス対応表**を持つ。

> **`.work/` 配下のパスが見つからないとき、「存在しない」と結論する前に必ず §3 の対応表を引くこと。**

## 1. 構成

```
.work/
├── README.md   ← このファイル（直下の唯一のファイル。hook が直下への書き込みを止める）
├── 証跡/       ← タスク md から参照される証跡。<タスクID>_内容/（複数タスク共有は YYYYMMDD_内容/）
├── 機密/       ← 外部から受領した一次資料そのもの。<タスクID>_内容/
├── 一時/       ← 使い捨て。YYYYMMDD_用途/ のサブフォルダ必須。**予告なく削除される**
└── _bk/        ← 移動・改名の前に取る退避コピー。参照元が無いことを確認してから消す
```

**直下は増やさない。** 仕組み（hook / skill / script）が固定パスで読み書きする枠を新設するときだけ、`.claude/rules/work-area.md` と本 README の両方へ追記する。

## 2. どこに置くか

| 問い | Yes なら |
|---|---|
| 仕組み（hook / skill / script）がパスを固定して読み書きするか | **直下**（本 README §1 に列挙したものだけ） |
| 外部から受領した一次資料そのものか | **`機密/<タスクID>_内容/`** |
| タスク md から参照される／される可能性があるか | **`証跡/<タスクID>_内容/`**（複数タスク共有は `YYYYMMDD_内容/`） |
| いずれも No（消してよい） | **`一時/YYYYMMDD_用途/`** |

迷ったら `証跡/`。判断基準の詳細・禁止事項は `.claude/rules/work-area.md`。
