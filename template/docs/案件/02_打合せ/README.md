# 02_打合せ/ — 打合せ記録

打合せ 1 回につき 1 ファイル。ファイル名は `YYYYMMDD_タイトル.md`（例: `20260101_キックオフ.md`）。

## 書式

```markdown
# YYYY-MM-DD タイトル

- 出席: （役割で書く。顧客の個人名を出すかは 案件情報.md §1.4 の連絡ルールに従う）
- 目的:

## 決定事項
- （1 行 1 決定。関連タスク ID / ADR を付ける）

## 宿題
| 誰が | 何を | 期限 | 関連タスク ID |
|:--|:--|:--|:--|

## 議論の要点
- （決定に至らなかった論点・保留の理由）

## 次回
- 日程・議題
```

## 運用

- 決定事項はここに書くだけで終えず、該当タスク md（過去の経緯）か ADR へ反映する
- 日程・先方待ちが変わったら `案件情報.md` を `update-env-info` スキルで更新する
- 相手への確認事項が生まれたら `../確認依頼一覧.md` へ
- 文字起こし全文はここに置かず、要約だけを残す。全文が要るなら `.work/証跡/YYYYMMDD_打合せ全文/` へ（`.claude/rules/work-area.md`）
- 秘密（URL・ID・パスワード）は書かない
