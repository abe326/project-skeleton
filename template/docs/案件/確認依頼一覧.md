# 確認依頼一覧

相手（発注側・顧客・レビュアー）に**確認・判断・対応をお願いしたいこと**を 1 か所に集める。「今お願いしたいことだけ」を上に置き、片付いたものは履歴節へ移す。

- **書式**: `- [ ] **何が変わった／何を決めてほしい** — 開く場所: … ／ OK の状態: …（日付 / タスク ID）`
- **凡例**: `[ ]` 未確認 ／ `[x]` 確認済（→ 履歴へ） ／ `[~]` 取り下げ（→ 履歴へ）
- **更新**: 依頼が生まれたら 1 行足す。回答を得たらタスク md に反映し、行を履歴へ移す。`案件情報.md` §4「先方待ち・未決」と重複させない（こちらは相手向けの文面、あちらは当方の状態管理）
- 秘密（URL・ID・パスワード）は書かない。開く場所は画面名・メニュー名で示す
